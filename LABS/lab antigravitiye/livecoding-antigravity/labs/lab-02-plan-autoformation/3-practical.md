# Mise en pratique : préparer son autoformation à Laravel

Dans cet exercice, vous allez transformer le plan de cours Laravel fourni en parcours d'autoformation. L'objectif est de planifier l'apprentissage et la pratique, pas de réaliser toute l'installation pendant cette activité.

## Matériel requis

* Le document [Plan de cours : Laravel](../../../../laravel_course_outline%20%281%29.md).
* Un éditeur de texte ou un document pour rédiger votre plan.
* Un créneau réaliste pour apprendre et pratiquer.

## Étapes

### 1. Définir votre objectif

À partir du plan de cours, complétez la phrase :

> À la fin de mon parcours, je pourrai expliquer ce qu'est Laravel et son fonctionnement général, puis lancer un premier exemple « Hello World ».

Vous pouvez préciser cet objectif selon votre contexte et vos acquis.

### 2. Faire le point sur vos prérequis

Notez votre niveau ou vos questions pour chacun de ces sujets :

* PHP ;
* Composer ;
* MySQL ;
* développement web et architecture MVC.

Ne supposez pas que ces outils sont déjà installés. Dans votre plan, indiquez comment vous vérifierez les prérequis et où vous chercherez une aide si une installation pose problème.

### 3. Organiser le parcours en étapes

Reprenez les thèmes du plan de cours dans un ordre qui prépare à la pratique :

1. **Comprendre les notions** : framework, Laravel, architecture MVC et fonctionnement général.
2. **Préparer l'environnement** : identifier et vérifier PHP, Composer et MySQL nécessaires au parcours.
3. **Démarrer avec Laravel** : suivre une ressource adaptée pour lancer un premier exemple « Hello World ».
4. **Faire le bilan** : expliquer ce que vous avez compris, consigner les difficultés et choisir la prochaine étape.

Pour chaque étape, choisissez une ressource précise et une activité qui vous permettra d'utiliser ce que vous avez appris.

### 4. Rédiger votre plan

| Étape | Ce que je veux apprendre ou réaliser | Ressource à consulter | Activité ou preuve de réussite | Échéance |
| --- | --- | --- | --- | --- |
| Définitions et MVC | Expliquer les notions de framework, Laravel et MVC | | Expliquer les notions avec mes propres mots et donner un exemple | |
| Fonctionnement | Décrire le fonctionnement général de Laravel | | Faire un schéma ou un court résumé | |
| Outils | Vérifier les prérequis PHP, Composer et MySQL | | Noter les versions et les éventuels problèmes rencontrés | |
| Premier démarrage | Lancer un premier exemple « Hello World » avec Laravel | | Montrer le résultat et décrire les étapes suivies | |
| Autoformation | Organiser la suite de mon apprentissage | | Choisir une prochaine notion à approfondir | |

### 5. Prévoir le suivi

À la fin de chaque étape, répondez aux questions suivantes :

* Qu'est-ce que je sais expliquer ou faire maintenant ?
* Quelle preuve ai-je conservée : notes, schéma, résultat affiché ou étapes suivies ?
* Quelle difficulté dois-je résoudre avant de continuer ?
* Mon rythme et mes échéances sont-ils réalistes ?

## Résultat attendu

Vous obtenez un plan d'autoformation Laravel qui reprend les thèmes du plan de cours, relie chaque étape à une activité pratique et prévoit des preuves de progression ainsi que des bilans.

## Défi

Présentez votre plan à un autre apprenant. Demandez-lui si les étapes et les preuves de réussite sont claires. Ajustez ensuite une étape pour la rendre plus précise ou plus réaliste.
