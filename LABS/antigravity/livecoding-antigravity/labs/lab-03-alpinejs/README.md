# Lab 03 : Découvrir Alpine.js

## Sujet
Comprendre les bases d'Alpine.js et créer une petite interaction directement dans une page HTML.

## Objectifs pédagogiques
À la fin de ce lab, vous pourrez :
* expliquer ce qu'est un framework et situer Alpine.js ;
* décrire le fonctionnement d'un composant Alpine avec `x-data` et des directives ;
* préparer une page HTML et réaliser un premier exemple interactif ;
* organiser une prochaine étape d'autoformation à partir d'un objectif concret.
