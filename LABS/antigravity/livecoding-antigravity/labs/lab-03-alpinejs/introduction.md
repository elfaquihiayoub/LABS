# Introduction à Alpine.js

Alpine.js permet d'ajouter des interactions à une page HTML en déclarant l'état et le comportement directement dans le balisage. Il convient notamment aux petites interfaces ou aux pages qui ont besoin de comportements réactifs sans adopter une architecture JavaScript plus lourde.

Ce lab suit les étapes du plan d'apprentissage : définir les notions utiles, préparer les outils et réaliser un premier démarrage. Laravel est un exemple pratique dans le plan, pas un prérequis pour apprendre Alpine.js.

## Objectifs pédagogiques

À la fin de ce lab, vous pourrez :
* expliquer ce qu'est un framework et décrire le rôle d'Alpine.js ;
* expliquer comment un état déclaré avec `x-data` est utilisé par les directives ;
* créer et tester une interaction simple dans un navigateur ;
* choisir une prochaine notion à apprendre et planifier sa pratique.
