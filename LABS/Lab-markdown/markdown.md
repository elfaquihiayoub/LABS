# INTRODUCTION

## Qu’est-ce que Markdown ?

- Langage de balisage léger
- Fichiers en texte brut : `.md`
- Syntaxe simple et lisible
- Utilisé dans les projets web et sur GitHub

---

# PROBLÈME 1
## Documentation difficile à lire

- Texte désorganisé
- Titres et listes peu visibles
- Lecture moins rapide

---

# PROBLÈME 2
## Formatage compliqué

- Mise en forme manuelle répétitive
- Difficulté à garder une structure cohérente
- Documents difficiles à maintenir

---

# PROBLÈME 3
## Tâches et informations dispersées

- Instructions non centralisées
- Idées et tâches oubliées
- Informations difficiles à retrouver

---

<!-- _class: title -->

# SOLUTIONS

## Utiliser Markdown

- Structurer le contenu
- Garder les fichiers faciles à modifier
- Documenter les projets

---

<!-- _class: solution -->

# SOLUTION 1
## Structurer avec une syntaxe simple

- `# Titre`
- `## Sous-titre`
- `- Élément de liste`
- `**Texte important**`

---

# SOLUTION 2
## Créer des documents faciles à maintenir

- Fichiers `.md` en texte brut
- Modification dans Visual Studio Code
- Formatage cohérent grâce à Markdownlint

---

# SOLUTION 3
## Centraliser les informations

- Notes et consignes dans des fichiers `.md`
- Tâches avec des listes à cocher :
  - `- [ ] Tâche à réaliser`
  - `- [x] Tâche terminée`
- Documentation partageable avec le projet

---
