# Découverte de Laravel

## 1. Qu’est-ce que Laravel ?

Laravel est un framework open source écrit en PHP qui permet de développer des applications Web de manière plus rapide, organisée et sécurisée.

## 2. Quel est le rôle de Laravel ?

Laravel joue principalement le rôle de partie serveur (**backend**) d’une application Web. Il reçoit les requêtes des utilisateurs, exécute la logique métier, communique avec la base de données et renvoie une réponse au navigateur.

## 3. Quels sont les avantages de Laravel ?

### 1. Développement rapide

Laravel propose des fonctionnalités intégrées qui évitent de réécrire le même code pour chaque projet.

### 2. Code organisé avec MVC

Il sépare les données, l’interface et la logique de contrôle, ce qui facilite la maintenance et le travail en équipe.

### 3. Sécurité

Il fournit des mécanismes de protection, notamment contre les attaques CSRF, ainsi que des outils pour l’authentification et la validation des données.

## 4. Comment Laravel est-il utilisé dans le développement Web ?

| Type d’application | Exemple |
|---|---|
| Site dynamique | Blog, site d’actualités |
| Application de gestion | Bibliothèque, gestion scolaire |
| E-commerce | Catalogue, panier, commandes |
| API REST | Backend pour React ou une application mobile |
| Plateforme SaaS | Gestion de projets, facturation |
